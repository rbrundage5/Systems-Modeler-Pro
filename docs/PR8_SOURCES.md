# PR8 normative source hierarchy

PR8 uses the following hierarchy when deciding BDD semantics and notation:

1. OMG SysML 1.6 normative specification and normative SysML XMI.
2. OMG UML 2.5.1 normative specification and normative UML metamodel for inherited UML semantics.
3. Existing standards-compatible `modeler-proto` behavior as the product migration baseline.
4. Previously accepted Systems Modeler Pro behavior and regression requirements.

If `modeler-proto` omits a standards-required concept, the omission is not carried forward merely for parity.
