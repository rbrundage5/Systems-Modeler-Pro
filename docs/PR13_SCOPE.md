# PR13 Scope Guard

PR13 is limited to native Activity modeling and the minimum shared infrastructure changes required to support it correctly.

In scope: Activity semantics, nodes/actions/pins, ControlFlow/ObjectFlow, partitions/structured regions, validation, SQLite persistence, desktop commands, Activity diagram presentation, shared routing integration, drill-down, and qualification.

Out of scope: requirements/traceability completion, use-case completion, parametric execution, verification evidence/execution, workbook import/reimport, collaboration/version control, global Symbol Properties, and a full behavior simulation engine.
